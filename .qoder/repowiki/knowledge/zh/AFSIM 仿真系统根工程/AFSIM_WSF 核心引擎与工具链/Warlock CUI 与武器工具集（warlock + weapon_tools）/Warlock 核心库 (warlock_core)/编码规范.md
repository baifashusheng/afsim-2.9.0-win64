- 所有对外可见的类均使用 WARLOCK_CORE_EXPORT 宏标记并通过 warlock_core_export.h 统一导出。
- Warlock 领域对象（Platform、Scenario 等）通过继承 wkf::* 基类并在 VA_DECLARE_OBJECT_TYPE 中注册，以便被脚本与序列化系统识别。
- 仿真线程与 GUI 线程之间的双向通信采用 SimCommand（GUI→仿真）与 SimEvent（仿真→GUI）队列模式，借助 UtConcurrentQueue 与 QMutex 保证线程安全。
- 可插拔 UI 组件（对话框、DockWidget、QWidget）统一通过 warlock::Factory 的 Create* 方法按字符串类型名实例化。
- 偏好设置采用三层结构：Preference Object（状态）+ Preference Widget（Qt UI）+ 可选 PrefDialog 组合，网络与仿真偏好分别成对实现。
