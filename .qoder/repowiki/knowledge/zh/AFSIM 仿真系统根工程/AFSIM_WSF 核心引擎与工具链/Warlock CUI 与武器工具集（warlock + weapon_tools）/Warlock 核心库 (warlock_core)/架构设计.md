模块以 CMake 构建为名为 warlock_core 的共享库（source/CMakeLists.txt），对外通过 warlock_core_export.h 暴露符号。

- 框架扩展点：WkFactory 继承 wkf::Factory，集中注册 Dialog/DockWidget/Widget/Scenario/Overlay 等可插拔 UI 与数据对象；WkfPlatform/WkfScenario 等基类在 wkf 层定义，本模块在其上派生 warlock::Platform、warlock::Scenario 并注入 Warlock 特有字段（传感器/武器/通信名称集、DisEntityId、XIO 控制标志）。
- 仿真线程交互：WkSimInterface.hpp 定义 SimCommand/SimEvent 抽象以及 SimInterfaceBase + 模板化 SimInterfaceT<EVENT_TYPE>，通过 UtConcurrentQueue 在 GUI 线程与仿真线程之间安全传递命令与事件，支持 wall-clock / simulation-clock 两类周期回调。
- 事件管道：WkEventPipe 实现 WsfEventPipeLogger，由 CMake 中的 add_event_pipe_schema 从 wk_events.utpack 生成消息类型，经 EventPipeInterface 作为 WsfSimulationExtension 挂入仿真生命周期。
- 脚本接口：WkScriptSimInterface / WkScriptTypes 将 C++ 仿真对象暴露给 AFSIM 脚本语言，依赖 wsf_mil 以处理 WsfWeapon 参数类型。
- 网络与偏好：WkNetwork / WkNetworkData / WkNetworkPrefObject / WkNetworkPrefWidget 提供基于 Qt 的网络配置 UI；WkSimPrefObject / WkSimPrefWidget 同理封装仿真偏好。
- UI 资源：ui/ 下包含 .ui 文件与 warlock.qrc 资源清单，CMake 通过 configure_qt_project 自动编译。
- 文档：doc/ 下 RST 文档与 wk_*_extension.txt 描述各扩展点的接入方式，images/ 存放截图。
